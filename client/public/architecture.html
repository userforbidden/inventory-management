Data Flow & Integration

Request-Response Cycle

User Action (Filter Selection) ↓ useFilters Composable (State Update) ↓ Vue Component Watch Trigger ↓ API Call Built (api.js) ↓ HTTP GET with Query Params ↓ FastAPI Endpoint Handler ↓ apply_filters() & filter_by_month() ↓ Pydantic Validation ↓ JSON Response ↓ Frontend Computed Properties ↓ Template Rendering (v-for) ↓ Visual Display

State Management

Layer State Container Purpose

Core Data Models

InventoryItem

id: unique identifier | sku: product code | name: product name | category: Circuit Boards, Sensors, Actuators, Controllers | warehouse: San Francisco, London, Tokyo | quantity_on_hand: current stock | unit_cost: price per unit

Order

id: order identifier | order_number: customer ref | customer: customer name | items[]: line items array | status: Delivered, Shipped, Processing, Backordered | warehouse: fulfillment location | total_value: order amount in USD | order_date: ISO 8601 format

DemandForecast

item_sku: product identifier | current_demand: recent demand quantity | forecasted_demand: predicted quantity | trend: increasing, stable, decreasing | period: forecast timeframe (e.g., "Next 30 days")

BacklogItem

order_id: parent order | item_sku: product code | quantity_needed: shortage amount | days_delayed: fulfillment delay | priority: high, medium, low

Key Features & Capabilities

📦 Inventory Tracking

Real-time stock levels across 3 warehouses, 4+ categories. Monitor reorder points and calculate inventory value on-the-fly.

📋 Order Management

Full order lifecycle tracking (Processing → Shipped → Delivered). Multi-line items, expected vs actual delivery dates.

📊 Analytics Dashboard

KPI metrics, order health charts, inventory value by category, revenue tracking with monthly goals ($800K/month).

💰 Spending Analytics

Track costs across procurement, operational, labor, overhead. Monthly trends and category breakdowns.

🎯 Demand Planning

Demand forecasts with trend indicators. Backlog monitoring with priority-based shortage management.

🌐 Internationalization

Full English/Japanese support. Language-aware UI, currency conversion (USD/JPY), localized product names.

Important Design Decisions

Frontend Patterns

✓ Always use unique key in v-for loops (never index)

✓ Watch useFilters() for changes to reload API data

✓ Use computed properties for derived data (filtered, aggregated)

✓ Validate dates before calling .getMonth()

✓ Emit events for child→parent communication (no prop drilling)

Backend Patterns

✓ Filter on copies, never mutate original data arrays

✓ Check filter value !== 'all' before applying filter

✓ Use lowercase for category/status comparisons

✓ Always return Pydantic-validated response_model

✓ Handle missing/null date values gracefully

Data Consistency

• Categories: Circuit Boards, Sensors, Actuators, Controllers, Power Supplies (consistent across files)

• Warehouses: San Francisco, London, Tokyo (exact match in all data)

• Dates: ISO 8601 format (YYYY-MM-DDTHH:MM:SS)

• Revenue Goals: $800K/month single, $9.6M YTD all months

• Orders span 12 months (Jan-Dec 2025)
